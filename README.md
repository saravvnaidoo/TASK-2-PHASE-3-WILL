## 📌 Executive Summary & Project Overview

**Next Level Gaming & Esports Arena** was founded in 2023 by Jason Naidoo to solve hardware limitations faced by local competitive gamers[cite: 2]. Playing fast-paced FPS games on older hardware (such as a PS4 failing to maintain 60fps) introduces latency and input lag, placing competitive players at a disadvantage[cite: 2]. 

This project delivers a responsive **Web and Mobile digital platform** where local gamers, competitive teams, and event organizers can browse packages, calculate booking fees, and reserve venue time on high-spec PCs and current-gen consoles[cite: 2].

## 📱 Platform Architecture & Wireframe Screens

The website and mobile application consist of **6 core screens** prototyped in Figma[cite: 1]:

1. **Home:** Promotes arena features, competitive news, and immediate booking entry points[cite: 1, 2].
2. **About Us:** Details Jason Naidoo's vision, venue backstory, and available equipment[cite: 1, 2].
3. **Overview:** Showcases venue hardware setups, high-spec PCs, and console stations[cite: 1, 2].
4. **Individual Course / Package Page:** Provides detailed breakdowns of hourly, group, and VIP packages[cite: 1].
5. **Calculate Fees:** Interactive pricing tool allowing users to estimate total booking costs[cite: 1, 2].
6. **Contact Us:** Venue location, operating hours, support forms, and inquiries[cite: 1].

## 📐 Web & Mobile Research Best Practices

### 1. Navigation
* **Web Navigation:** Primary header kept under seven items (Miller's Law / $7 \pm 2$), sticky headers for scrolling navigation, and persistent search controls[cite: 2].
* **Mobile Navigation:** Bottom-screen thumb zone navigation, fluid swipe gestures, and shallow menu depth (1–2 taps to reach core tasks)[cite: 2].

### 2. Layout & Responsive Design
* **Layout Patterns:** F-shaped and Z-shaped layout visual hierarchy placing key calls-to-action (CTAs) above the fold[cite: 2].
* **Grid Systems:** 12-column grid system for desktop and single-column layout for mobile viewports (375px–430px)[cite: 2].
* **Touch Sizing:** Interactive controls designed to meet Apple HIG (44×44 pt) and Google Material Design (48×48 dp) touch target specifications[cite: 2].
