## Project Overview

**Next Level Gaming & Esports Arena** was founded in 2023 by Jason Naidoo to give local gamers access to high-spec PCs and current-gen consoles without owning the hardware themselves.

This project is a responsive **web and mobile platform** where players, competitive teams, and event organizers can browse packages, calculate booking fees, and reserve venue time.

Built for the Work-Integrated Learning (WIL) component of the Higher Certificate in Mobile Application and Web Development, applying front-end development, UI/UX design, and version-control skills to a client-style brief. Plain HTML5, CSS3, and vanilla JavaScript are used throughout — no frameworks or build tools — keeping the fundamentals visible at this NQF Level 5 stage.
