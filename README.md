# Next Level Gaming & E-Sports Arena

A responsive, five-page static website for a community gaming venue. Visitors can explore the arena and its Competitive PC Package, estimate session fees, and contact the team. The contact form and calculator run in the browser; no booking or message is sent to a backend.

```text
|-- assets/
|   `-- README.md
`-- README.md
```

## Run with Live Server

1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open `index.html`, then select **Go Live** in the status bar (or right-click the file and choose **Open with Live Server**).

Google Fonts are optional; system fallbacks are defined in the stylesheet. The site can also be opened directly from `index.html`.
